//Descripción

// 1. **Ejercicio 1: Cotizador de envíos**
   * **Descripción:** Calcula el costo de envío de un paquete evaluando la zona de destino (local, departamental, nacional), el peso en kilogramos con su recargo, el tipo de servicio (estándar, express, mismo día) y el valor declarado. Incluye cálculo de seguro, aplicación de descuentos si supera el límite establecido y muestra un recibo detallado con formato de moneda.

//2. **Ejercicio 2: Simulador de carga de combustible**
   * **Descripción:** Simula una estación de servicio permitiendo elegir el tipo de combustible (regular, premium, diésel) y la cantidad de litros. Realiza la carga de forma progresiva en bloques de 5 litros utilizando un ciclo `while`, calcula el subtotal, aplica descuentos según el monto de la compra y muestra el resumen final.

//3. **Ejercicio 3: Control de asistencia a un taller**
   * **Descripción:** Utiliza arreglos estáticos precargados de participantes y asistencias (`true`/`false`). Permite listar la asistencia, calcular porcentajes, filtrar y mostrar a los ausentes mediante `foreach`, buscar un participante específico indicando su posición y mostrar los nombres en orden inverso con un ciclo `for`.

//4. **Ejercicio 4: Fila de atención de una clínica*
   * **Descripción:** Gestiona pacientes mediante listas (`List<string>`) separando filas urgentes y normales. Cuenta con un menú interactivo en bucle para registrar pacientes (validando duplicados y campos vacíos), atender al siguiente (dando prioridad estricta a urgencias), mostrar filas, buscar pacientes y consultar la cantidad total en espera.

//5. **Ejercicio 5: Inventario de una papelería**
 //* **Descripción:** Controla el inventario utilizando tres listas paralelas para nombres de productos, existencias y precios unitarios. Permite registrar nuevos productos, realizar ventas actualizando existencias y calculando totales, abastecer stock, mostrar el inventario detallado con el valor de cada producto y generar alertas automáticas de stock bajo junto con el producto de mayor valor.
